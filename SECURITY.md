# Security

Please report vulnerabilities privately, through GitHub's "Report a
vulnerability" (Security tab), not in public issues. Include what you found,
how to reproduce it, and the firmware and controller versions.

Areas we especially want to hear about: node adoption and device tokens, the
firmware update path, the setup page and setup network, and the console.

We'll acknowledge reports within a few days and credit you in the release
notes unless you'd rather not be named.
